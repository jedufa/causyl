# fallback absorption gate v1

phase-1 fallback learning is governed, not self-editing.

rules:
- every fallback event must record action family, failure class, deterministic attempts, checklist state, and post-fallback outcome
- absorption requires recurrence, stable failure class, repeatable solution path, bounded authority, and clear validation path
- positive economics is mandatory: expected future codex and operator cost must exceed build plus maintenance cost
- rejected cases stay recorded but do not create follow-on implementation work automatically
